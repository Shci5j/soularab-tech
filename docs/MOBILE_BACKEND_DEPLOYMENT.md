# تشغيل SOULARAB TECH محلياً على هاتف Android

## المبدأ
لا توجد استضافة خارجية أو اشتراك أو مزوّد مدفوع. يعمل تطبيق Android على الاتصال بخادم API ومحرك نموذج محليين على الهاتف نفسه عبر loopback فقط:
- API: `http://127.0.0.1:8000`
- محرك روح llama.cpp: `http://127.0.0.1:8081`

تطبيق الواجهة لا يشغّل Python أو نموذج اللغة تلقائياً داخل Android حالياً؛ لذلك تُشغّل الخلفية ومحرك النموذج بواسطة Termux. هذا تشغيل على الجهاز نفسه وليس خادماً سحابياً.

## تشغيل روح محلياً على الهاتف

من جذر مستودع SOULARAB TECH داخل Termux، شغّل أمراً واحداً:
`bash scripts/start-local-backend-termux.sh`

يقوم الإعداد بتثبيت متطلبات Termux، وبناء `llama.cpp` محلياً عند الحاجة، وتنزيل نموذج Qwen2.5-0.5B-Instruct بصيغة GGUF وكمية Q4_K_M (نحو 491 MB)، والتحقق من SHA-256، ثم تشغيل `llama-server` على `127.0.0.1:8081` قبل تشغيل API على `127.0.0.1:8000`. يضبط API تلقائياً على `ROOH_PROVIDER=llama_cpp`.

- النموذج الصغير نقطة بدء خفيفة للتجربة، وقد تكون قدرته على الاستدلال واللغة العربية محدودة مقارنة بنماذج أكبر.
- يتطلب تنزيل النموذج اتصال إنترنت أول مرة ومساحة حرة لا تقل عن 1.8 GB للبناء والنموذج.
- يمكن ضبط `ROOH_MODEL_PATH` و`ROOH_THREADS` و`ROOH_CONTEXT_SIZE` قبل تشغيل السكربت لتخصيص المسار والموارد.
- يبقى النموذج وواجهة API على loopback؛ لا يفتح السكربت أي منفذ على الشبكة أو الإنترنت.
- لا تحذف Termux أو بيانات `~/.soularab` بعد تنزيل النموذج إذا أردت الاحتفاظ به دون إعادة تنزيله.

## الإعداد الأول على الهاتف
1. ثبّت Termux من مصدره الرسمي (F-Droid أو GitHub الرسمي)، وافتحه.
2. نفّذ داخل Termux:
   `pkg install git`
   `git clone https://github.com/Shci5j/soularab-tech.git`
   `cd soularab-tech`
3. شغّل:
   `bash scripts/start-local-backend-termux.sh`
4. انتظر حتى يظهر أن Uvicorn يستمع على `127.0.0.1:8000`.
5. افتح تطبيق SOULARAB TECH. عنوان API الافتراضي في نسخة Android هو loopback المحلي.

## اختبار الخادم
افتح من متصفح الهاتف:
- `http://127.0.0.1:8000/api/health`
- `http://127.0.0.1:8000/docs`

يجب أن تعود حالة `ok` من health.

## شبكة الخوادم الخمسة
- A: النصوص والمحادثة
- B: الصور والتصميم
- C: الصوت والفيديو
- D: البرمجة والتطبيقات
- E: الاحتياطي وتوزيع المهام

من «الجذر» > «شبكة الخوادم الخمسة»، يمكن إضافة عنوان IP خاص لجهاز تملكه أو تثق به على الشبكة المحلية. لا يجري التطبيق مسح الإنترنت أو الاتصال بمزوّد خارجي. لا تسجّل عقدة إلا بعد استجابة health وتوافق بروتوكول SOULARAB MESH.

**تنبيه صريح:** اكتشاف العقد وتسجيلها وفحص اتصالها أصبح متاحاً في هذه المرحلة. تشغيل كل محرك AI على الهاتف، وتنفيذ المهام الموزعة تلقائياً بين خمسة أجهزة، يحتاج محرك عامل متوافقاً ومثبتاً على كل جهاز؛ لا تعتبر العقدة منفّذة للمهام لمجرد تسجيلها.

## القيود
- تشغيل الخادم المحلي يتطلب بقاء Termux قيد التشغيل.
- إغلاق Termux أو إيقاف عملية Uvicorn يوقف API.
- نماذج اللغة والصور والفيديو قد تتطلب ذاكرة ومعالجاً ومساحة تخزين أكبر مما يوفره الهاتف. لا يتم تنزيل نماذج ضخمة تلقائياً.
- لا تستخدم عناوين IP عامة؛ واجهة الشبكة تقبل loopback أو عناوين الشبكة الخاصة فقط.
