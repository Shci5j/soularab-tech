# نشر خادم SOULARAB TECH وربطه بتطبيق Android

## ما الذي يجهزه هذا الملف؟
- ينشر صورة Docker الموحدة (واجهة الويب + FastAPI خلف Nginx) كخدمة واحدة.
- ينشئ رمز API عشوائياً من منصة الاستضافة ولا يضعه في Git.
- يربط قاعدة SQLite بمساحة تخزين دائمة.
- يضيف أصول Capacitor (https://localhost وcapacitor://localhost) إلى CORS.

## نشر الخدمة
1. افتح Render وأنشئ Blueprint جديداً من مستودع Shci5j/soularab-tech والفرع feature/engines-security-android.
2. راجع الخطة قبل التأكيد: ملف Blueprint يطلب خطة Starter وقرصاً دائماً 1GB، وقد تترتب عليهما رسوم حسب تسعير حسابك.
3. بعد اكتمال النشر، افتح الخدمة soularab-tech-api وانسخ عنوان HTTPS العام. اختبر /api/health؛ يجب أن يعيد حالة سليمة.
4. من GitHub > Settings > Secrets and variables > Actions > Variables، أضف متغيراً باسم VITE_API_BASE_URL وقيمته عنوان HTTPS للخدمة دون مسار أو شرطة أخيرة.
5. من GitHub > Actions شغّل workflow باسم Android debug APK. يتوقف البناء عمداً إذا كان المتغير غير مضبوط، حتى لا نصدر APK يعرف أنه غير قادر على الاتصال بالخادم.
6. نزّل artifact الجديد وثبّته. افتح التطبيق وأدخل رمز الوصول الذي أنشأه Render من صفحة Environment للخدمة (لا تنشره ولا ترسله في محادثة).
7. من الإعدادات افحص الاتصال. يجب أن يظهر الخادم متصلاً قبل تجربة الأقسام المعتمدة على API.

## حدود مهمة
- نشر API لا يعني أن Ollama أو ComfyUI أو whisper.cpp أصبحت مثبتة أو متصلة. هذه محركات منفصلة؛ تبقى حالة المساعد/الصور/الصوت غير متاحة حتى تشغيلها وربطها ضمن شبكة آمنة مناسبة.
- خدمة Render لا تستطيع الوصول إلى 127.0.0.1 على هاتفك أو حاسوبك. العناوين الافتراضية للمحركات محلية داخل حاوية الخادم، وليست عنوان جهازك.
- لا تفتح منافذ Ollama أو ComfyUI أو Whisper مباشرة للإنترنت. يلزم نشر خاص/شبكة خاصة أو نفق موثوق مع مصادقة.
- لا يوجد عامل مهام عام أو تنفيذ تلقائي. الإجراءات التي لا يعلنها سجل التنفيذ كإجراءات مسموحة تبقى غير منفذة.
- لا تضع رمز API أو مفاتيح الاستضافة أو keystore في المستودع أو في المحادثة.

## تشغيل ذاتي بدلاً من Render
يمكن تشغيل docker compose على خادم تملكه. انسخ .env.docker.example إلى .env، واستبدل قيمة SOULARAB_API_TOKEN بسر عشوائي قوي، واضبط SOULARAB_CORS_ORIGINS على النطاقات الفعلية فقط، ثم شغّل docker compose up -d --build. لا تستخدم المثال الافتراضي للرمز في بيئة فعلية.
